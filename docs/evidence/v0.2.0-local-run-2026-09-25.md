## Education corpus evaluation on the real Kaggle release

```powershell
python -m rag_platform evaluate --education-dir <extracted lucasrangelss/brazil-education-data-lake v1> \
  --max-municipalities 40 --output artifacts/eval-edu.json
```

The adapter verified the release manifest (SHA-256 `44f259602a688432dddbae6b0306a6957514a634d57d94a0abd3cff30f4b3506`) before building 41 documents (40 sampled municipalities, evenly spaced over sorted IBGE codes, plus one dataset-card document) from the semantic layer.

| Metric | Value | n |
|---|---|---|
| recall@3 | 0.9877 | 81 |
| citation coverage | 0.9383 | 81 |
| correct abstention rate | 1.0 | 6 |

81 cases: two per sampled municipality (a maintenance-and-development share question and a population question) plus the dataset-card case. The gap between recall and citation coverage means a few answers retrieved the right document but the extractive generator's sentence selection did not carry a citation to it in every case; this has not been broken down further.

## Docker

```powershell
docker build -t rag-platform:0.2.0 .
docker compose --profile fixture up -d
curl http://127.0.0.1:8080/healthz
curl -X POST http://127.0.0.1:8080/v1/answer -H "Content-Type: application/json" -d "{\"question\":\"How does the retrieval service abstain?\"}"
docker compose --profile fixture down
```

Image built successfully (`sha256:67e7ff33...`). The container served `/healthz` and answered a fixture question with a citation.

```powershell
EDUCATION_RELEASE_DIR=<extracted release> docker compose --profile education up -d
curl http://127.0.0.1:8081/healthz
curl -X POST http://127.0.0.1:8081/v1/answer -H "Content-Type: application/json" -d "{\"question\":\"What was the population of Acrelandia in 2023?\"}"
docker compose --profile education down
```

`/healthz` reported 5,568 documents (5,567 municipalities plus the dataset card). The answer cited `municipality-1200013#c004`, carried the dataset slug, version, and manifest hash in the citation, and listed all five source record ids for that municipality. The container took about 10 seconds to become healthy while it built the corpus from the Parquet layer on startup; the health check's `start_period` (10s) covers this.
